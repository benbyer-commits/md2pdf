# md2pdf

A lightweight Node.js CLI tool to convert Markdown files to clean PDF documents.

## Installation

```bash
npm install
```

## Usage

```bash
node ./bin/index.js <input-file> [options]
```

### Options
* `-o, --output <path>`: Destination path for generated PDF.
* `-v, --version`: Display current CLI version.
* `-h, --help`: Display usage instructions.

## Testing

```bash
npm test
```
